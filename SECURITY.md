# Security policy

Dusk runs on machines its operators cannot reach, for a very long time,
so reports are handled privately until a fix is out.

## Reporting a vulnerability

Do not open a public issue. Report it through GitHub's private
vulnerability reporting on this repository: the **Security** tab, then
**Report a vulnerability**. Include the version or commit, the part of the
project it is in, what an attacker can do, and how to reproduce it.

You will get an acknowledgement within seven days. The owner assesses the
report, works on a fix in private, and tells you when it ships. The
release notes for the fix credit you unless you ask them not to.

## Supported versions

Until the first stable release, only the latest commit on `master` is
supported, and fixes are released from there.

## Scope

In scope: anything in this repository. Out of scope: the third-party
material the README lists, which is reported upstream, and code that is
not in this repository, even when it is built on Dusk.
